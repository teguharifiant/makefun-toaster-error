## The entry

> ERROR E12: The bread has unionised. Negotiations have broken down.

66 characters. Deadpan, in the voice of a small appliance reporting a labour dispute it cannot resolve.

## How to run

Requires Node 22.18 or later (TypeScript runs as-is).

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## How it works

`main.ts` holds the entry as a single constant and writes it, byte-identical on every run, to `entry.txt`. No network, no input, no dependencies — the program is fully self-contained.
